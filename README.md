### 😱 게임 소개

Invisiphobia : null path 는 보이지 않는 물체와 그 사이에 있는 괴물들로 가득 찬 미궁에서 펼쳐지는 **3D 1인칭 호러 어드벤처 게임**입니다.            

**소중한 사람을 구출**하기 위해 당신은 보이지 않는 존재들을 조심스럽게 **탐색**하고, 갑작스럽게 나타나는 위협을 경계하며 살아남고, 마지막엔 구출 대상을 구해 당신이 들어왔던 지하실 입구로 되돌아 나가야 합니다.
